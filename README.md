# khoreh.com

The website for Maplewick, a focus game for ADHD minds.

- `index.html` is built from `src/home.html` by `python3 build.py` (do not edit it by hand).
- `privacy.html` and `support.html` are the pages the App Store listing links to.
- `CNAME` tells GitHub Pages to serve this site on khoreh.com.
- `app-ads.txt` authorizes Google AdMob to sell ads in apps that list khoreh.com as their developer website (Due by Dusk).
- `due-by-dusk/privacy.html` is the privacy policy for Due by Dusk, the farming game.
